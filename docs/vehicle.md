## Notes

0603/AIH is listed for the 103 kW 1.4 TSI Touran. Across the 1T3 production range the same power class can also be associated with CTHC, so ECU identity must be checked on the actual car. This repository targets the CAVC configuration supplied for this project.

Recommended identity capture:
- VIN
- ECU part number
- ECU software number/version
- protocol
- calibration/CVN where available
- VCDS Auto-Scan
- VCDS controller map for 01-Engine
